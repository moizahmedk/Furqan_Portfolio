How to publish

  1. Provide title, category, description, and either image URL or file upload.
  2. Enter your GitHub owner, repository, branch, and personal access token.
  3. Click Save directly to GitHub to upload the image and update data/photos.json.
  4. If you only want metadata, click Generate metadata and paste JSON into data/photos.json.

This page can save content directly to GitHub, so you do not need local storage for image data if you upload files here.
