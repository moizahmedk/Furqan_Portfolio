How to publish

  1. Use the form to generate new photo metadata.
  2. Download the JSON snippet or copy the previewed entry.
  3. Paste the new entry into data/photos.json.
  4. Optionally run scripts/add-photo.ps1 to add a local image and push changes.

Because this is a static portfolio, browser save access is limited. Use the PowerShell helper for direct GitHub commits and image additions.
