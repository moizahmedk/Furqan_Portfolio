About this Project

GitHub-powered static portfolio with an admin workflow

This project is designed to keep photographic work in a Git repository. New photo metadata can be prepared in the admin workflow, then committed and pushed to GitHub so the repo acts as the content store.

  • Landing page with featured gallery preview
  • Dedicated gallery detail page for each photo
  • Admin page for new photo metadata and previews
  • PowerShell scripts to update JSON, add images, and push to GitHub
